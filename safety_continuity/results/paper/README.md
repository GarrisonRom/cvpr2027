# Reviewed Paper Artifacts

Only reviewed figures and tables that are ready to cite in the paper belong here. Exploratory outputs remain under the ignored runs/<run_id>/ tree.

- figures/ contains final figures and their editable source/config where practical.
- tables/ contains final CSV source tables and LaTeX exports.
- result_index.yaml maps each artifact to the runs, analysis config and Git commit that produced it.

Do not edit numerical values inside exported figures or tables by hand. Regenerate them from validated run summaries.
